# Шорты — ориентиры проекта

Мобильный веб-прототип сервиса коротких вертикальных сериалов. Интерфейс на русском.
Стек: React 19 + Vite + TypeScript. Приложение живёт внутри симулятора телефона,
который приходит из шаблона.

## Где что лежит

- `src/content/catalog.json` — каталог сериалов, жанры, подписи вкладок, сериал
  экрана «Для вас». Описание всех полей: `CONTENT.md`.
- `public/assets/posters/`, `public/assets/feed/` — постеры. Вертикальные, 2:3.
- `src/Prototype.tsx`, `src/prototype.css` — вся вёрстка и логика приложения.
- `src/mobile/` и соседние файлы рантайма — симулятор телефона, см. ниже.

При добавлении сериала: `id` уникален, латиницей через дефис, и у существующих
записей не меняется — на него ссылаются избранное и история просмотра. Значения
`genre` должны встречаться в списке `genres`, иначе фильтр их не найдёт.

## Защищённый рантайм

`src/mobile/`, `src/App.tsx`, `src/main.tsx`, `src/styles.css`, `vite.config.ts`,
`worker/index.js`, `scripts/`, `public/assets/iphone/`, `public/assets/android/`,
`public/assets/status/` — рантайм симулятора телефона из шаблона.

Его целостность проверяется по SHA-256 на `predev` и `prebuild`: `npm run check:runtime`.
Это не соглашение, а гейт сборки — если хеш не сходится, запуск падает. Менять эти
файлы можно, но тогда нужно осознанно обновить лок `mobile-runtime.lock.json`,
убедившись, что новое поведение рантайма действительно то, что нужно. Обходить или
ослаблять проверку не стоит: она ловит случайные правки.

Детали контракта рантайма и накопленные дизайн-решения: `AGENTS.md`.

## Дизайн

Ориентир — Apple Human Interface Guidelines, а не придуманные на месте решения:
минимальная зона нажатия 44×44pt, типографика по шкале iOS, штатная анатомия
навбара и таббара, системное поведение шитов и алертов. Если визуальный референс
спорит с HIG — поведение по HIG, бренд и цвет по референсу. Раздел «Design Authority»
в `AGENTS.md`.

## Проверка перед сдачей

```
npm run check:runtime   # целостность рантайма
npx tsc                 # типы
npm run dev             # посмотреть глазами
```

Для правок каталога достаточно убедиться, что `catalog.json` — валидный JSON
и приложение открывается без ошибок в консоли.
