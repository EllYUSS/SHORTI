# Шорты — правила проекта

Мобильный веб-прототип сервиса коротких вертикальных сериалов. Интерфейс на русском.
Стек: React 19 + Vite + TypeScript. Прототип живёт внутри симулятора телефона.

## Роли

В проекте две роли, и у каждой своя зона файлов.

**Контент.** Наполняет каталог и тексты страниц. Работает ТОЛЬКО в:
- `src/content/` — каталог сериалов и тексты
- `public/assets/posters/`, `public/assets/feed/` — изображения

**Разработка.** Вёрстка, логика, дизайн. Всё остальное.

Если задача пришла от контент-роли, менять файлы вне её зоны нельзя. Нужна правка
вёрстки или поведения — не делай её, а напиши, что это задача для разработки.

## Как добавлять контент

Каталог: `src/content/catalog.json`. Полное описание полей — в `CONTENT.md`.
Короткий путь: положить постер в `public/assets/posters/`, добавить объект в массив
`shows`, проверить что JSON валиден.

Правила:
- `id` уникален, латиницей через дефис, у существующих сериалов не меняется —
  на него ссылаются избранное и история просмотра.
- Значения `genre` должны встречаться в списке `genres`, иначе фильтр их не найдёт.
- Постеры вертикальные, пропорции 2:3.

## Что нельзя трогать никому без явной просьбы владельца

`src/mobile/`, `src/App.tsx`, `src/main.tsx`, `src/styles.css`, `vite.config.ts`,
`worker/index.js`, `scripts/`, `public/assets/iphone/`, `public/assets/android/`,
`public/assets/status/` — это защищённый рантайм симулятора телефона. Его целостность
проверяется по хешам: `npm run check:runtime`. Если проверка падает — восстанови файлы,
а не правь лок и не обходи проверку.

Подробные правила рантайма и дизайн-решения: `AGENTS.md`.

## Дизайн

Источник истины — Apple Human Interface Guidelines. Ничего не выдумываем от себя:
минимальная зона нажатия 44×44pt, типографика по шкале iOS, штатное поведение
шитов и алертов. Раздел «Design Authority» в `AGENTS.md`.

## Проверка перед сдачей

```
npm run check:runtime   # целостность рантайма
npx tsc                 # типы
npm run dev             # посмотреть глазами
```

Для контент-правок достаточно убедиться, что `catalog.json` — валидный JSON
и приложение открывается без ошибок в консоли.
