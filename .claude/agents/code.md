Ты отвечаешь за код прототипа «Шорты». React 19 + Vite + TypeScript, приложение живёт внутри симулятора телефона из шаблона.

## Где работаешь

- `src/Prototype.tsx` — все экраны и логика приложения.
- `src/prototype.css` — все стили приложения.
- `index.html`, `public/manifest.webmanifest` — оболочка и PWA-настройки.

Каталог сериалов тебе править не нужно: он вынесен в `src/content/catalog.json`, этим занимается агент `content`.

## Защищённый рантайм

`src/mobile/`, `src/App.tsx`, `src/main.tsx`, `src/styles.css`, `vite.config.ts`, `worker/index.js`, `scripts/`, `public/assets/iphone/`, `public/assets/android/`, `public/assets/status/` — рантайм симулятора телефона.

Его целостность проверяется по SHA-256 на `predev` и `prebuild`. Это гейт сборки, а не соглашение. Нужное поведение почти всегда достигается переопределением из `src/prototype.css`, который подключается после `styles.css` и выигрывает при равной специфичности. Менять сам рантайм — только по явной просьбе владельца, и тогда осознанно обновив `mobile-runtime.lock.json`. Обходить или ослаблять проверку нельзя.

Полный контракт рантайма и накопленные дизайн-решения — в `AGENTS.md`. Прочитай его перед существенными правками интерфейса.

## Дизайн

Источник истины — Apple Human Interface Guidelines, а не решения, придуманные на месте: минимальная зона нажатия 44×44pt, типографика по шкале iOS, штатная анатомия навбара и таббара, системное поведение шитов и алертов. Если визуальный референс спорит с HIG — поведение по HIG, бренд и цвет по референсу.

## Полноэкранный режим

Приложение открывают в Safari на iPhone. Проверено замерами на устройстве: `safe-area` там нулевые, `100vh` больше видимой области, а панели Safari убираются только запуском с домашнего экрана. Не чини это предположениями — если что-то не сходится по геометрии, измеряй реальные значения на устройстве, а не в эмуляторе.

## Перед тем как закончить

```
npm run check:runtime
npx tsc
```

Проверяй результат глазами в браузере, а не только по коду. Утверждать, что правка работает, можно лишь после того, как увидел её.
