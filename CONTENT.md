# Как добавлять контент

Весь каталог живёт в одном файле: `src/content/catalog.json`.
Код трогать не нужно — приложение само подхватывает изменения.

## Добавить сериал

1. Положи постер в `public/assets/posters/`. Формат PNG или JPG, вертикальный,
   пропорции 2:3 (например 1024×1536).
2. Открой `src/content/catalog.json` и добавь объект в массив `"shows"`:

```json
{
  "id": "unikalnyy-id",
  "title": "Название сериала",
  "genre": "Мелодрама",
  "category": "Мелодрама",
  "views": "12,5 млн",
  "image": "/assets/posters/imya-faila.png",
  "badge": "Новинка",
  "episodes": 48,
  "currentEpisode": 1,
  "summary": "Описание в два-три предложения.",
  "cast": [
    { "name": "Имя актёра", "role": "Имя героя", "image": "/assets/posters/imya-faila.png" }
  ],
  "isNew": true
}
```

## Что означают поля

| Поле | Что это |
|---|---|
| `id` | Уникальный ключ латиницей через дефис. Не повторяется и не меняется. |
| `title` | Название на карточке и на странице сериала. |
| `genre` | Подпись под названием на карточке. |
| `category` | Группа для фильтра. |
| `views` | Просмотры — текст как есть, например `159,3 млн`. |
| `image` | Путь от корня сайта: `/assets/posters/...`. |
| `video` | Необязательно. Путь к видео: `/assets/video/...`. Без него плеер показывает постер. |
| `badge` | Плашка на постере: `В тренде`, `Хит`, `Новинка`. Можно убрать. |
| `episodes` | Всего серий. |
| `currentEpisode` | С какой серии открывается плеер. |
| `summary` | Описание на странице сериала. |
| `cast` | Актёры: имя, роль, фото. |
| `isNew` | `true` — попадает во вкладку «Новинки». |

## Добавить видео

Положи файл в `public/assets/video/` и укажи путь в поле `video` у сериала:

```json
"video": "/assets/video/prison-king.mp4"
```

Требования к файлу:

- **Формат MP4**, кодек H.264, звук AAC. Это единственное сочетание, которое
  играет во всех браузерах, включая Safari на iPhone.
- **Вертикальное**, пропорции 9:16 — например 1080×1920. Горизонтальное видео
  обрежется по бокам.
- **Вес** держи в пределах нескольких мегабайт: файл грузится по сети, и на
  мобильном интернете тяжёлое видео будет долго стартовать.

Как это работает на экранах:

- **Плеер сериала** — видео со звуком, запускается по нажатию на кнопку play.
  iOS не разрешает включать звук без действия пользователя, поэтому
  автозапуска там нет намеренно. Полоса перемотки двигает видео.
- **Лента «Для вас»** — видео запускается само, без звука и по кругу, как
  принято в вертикальных лентах.
- **Главный экран** — в сетке всегда постер, даже если у сериала есть видео.
  Карточки ничего не проигрывают.

Поле необязательное: у сериала без `video` всё работает как раньше, показывается
постер. Постер нужен в любом случае — он служит первым кадром, пока видео
грузится, и запасным вариантом, если файл не открылся.

## Остальные поля файла

- `genres` — список для фильтра по жанрам. Значения должны совпадать с `genre` у сериалов.
- `categoryLabels` — подписи вкладок наверху.
- `featured` — сериал на экране «Для вас». Поля те же, что у обычного сериала.

## Правила

- Файл должен остаться валидным JSON: запятая между объектами, но не после последнего;
  все строки в двойных кавычках.
- `id` не меняй у уже существующих сериалов — на них ссылаются избранное и история.
- Не редактируй файлы вне `src/content/` и `public/assets/posters/`.
